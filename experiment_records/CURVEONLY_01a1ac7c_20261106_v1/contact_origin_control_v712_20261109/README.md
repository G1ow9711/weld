## 使用

在仓库根目录、原环境或兼容环境中运行：

```bash
python -m tools.curveonly_01a1ac7c_infer_contact_origin_v718 --verify-only
python -m tools.curveonly_01a1ac7c_infer_contact_origin_v718 --xyz /absolute/workpiece.npy --step /absolute/material.stp --out /absolute/result
```

主要输入为毫米单位的纯XYZ点云（PLY或NPY）与原始材料实体STEP。可选`--pose-config`用于事先约定、不含焊缝答案的STEP→XYZ 4×4变换；省略时沿用原自动配准。无STEP时入口保留原点云回退能力，本次接触修复只作用于配准合格的有限STEP接头。输出`curves.json`、`complete_curves.csv`和`run.json`。

- 当前成绩摘要：同目录`EVALUATION_SUMMARY.json`。
